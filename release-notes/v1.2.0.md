# DriverUpdate Pro v1.2.0

DriverUpdate Pro 1.2.0 focuses on NVIDIA driver handling, download visibility, background behavior, and release polish.

## Highlights

- New Driver Tools tab for quick access to update-related tools and downloads
- Direct NVIDIA driver package downloads from inside the app
- Correct latest NVIDIA DCH package resolution for supported GPUs
- Download progress, pause, resume, cancel, and open-folder actions
- Direct package vs Smart link NVIDIA mode in Settings
- Optional startup auto-download for NVIDIA packages in Direct mode
- Notification center with clearable history in the title bar
- Close-to-tray background mode
- Automatic app update downloads when auto update checks are enabled
- Version normalization to 1.2.0 across the app and installer

## NVIDIA Improvements

- The app now resolves the latest official NVIDIA package for supported display GPUs and downloads it directly instead of only opening NVIDIA's site.
- NVIDIA version checks now use a live lookup instead of a stale placeholder value.
- The NVIDIA resolver now prefers the current DCH branch, preventing older legacy packages such as `472.12` from being selected when newer packages are available.
- RTX 20 desktop mappings were corrected so desktop and notebook packages are no longer mixed up for those GPUs.

## UX Improvements

- Added a persistent download banner and title-bar status indicator.
- Added pause, resume, cancel, and open-folder actions for active downloads.
- Added a notification button with a clearable history for important app events.
- Added a background-mode option so closing the window can minimize the app to the tray.
- Improved Settings layout and NVIDIA settings presentation.

## Validation

- Built successfully with `npm run build`
