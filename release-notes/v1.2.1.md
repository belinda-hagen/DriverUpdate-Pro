# DriverUpdate Pro v1.2.1

DriverUpdate Pro 1.2.1 is a maintenance release that fixes a recurring NVIDIA auto-download issue.

## Bug Fixes

- **NVIDIA auto-download no longer restarts after being cancelled.** Previously, if you stopped or cancelled the automatic NVIDIA package download, closing and reopening the app would start the download again. The app now remembers which driver version the startup auto-download has already handled (whether it finished or you cancelled it) and will not restart it for that same version. A newer NVIDIA driver version re-arms the auto-download as expected.

## Notes

- Transient download failures (interrupted connection or errors) are intentionally still retried on the next launch, so only an explicit finish or user cancellation stops the auto-download from repeating.
- Manually starting a download from a driver card or the Driver Tools tab is unaffected.
